# 一个字的一生

**甲骨文 → 小篆 → 繁体 → 简体** —— 看一个汉字三千年的样子。

🔗 **在线访问**：<https://ivan666jjj.github.io/yigezi/>

---

## 这是什么

输入任意汉字，一页看完它的**形、音、义、族**：

| 维度 | 内容 |
|---|---|
| **形** | 甲骨文 → 小篆 → 繁体 → 简体（四体时间轴，从商代一路到今天的演变，带年代标注） |
| **音** | 现代拼音 · 中古音反切与音韵地位 · 上古音构拟 |
| **义** | 《说文解字》原文 + 反切 + 部首 + 卷次 + 重文 |
| **族** | 谐声系列（同声符字族，可点击跳转） |

外加：

- **古文字纠正**：部分字给出「《说文》说 ××，甲⾻文实为 ××」的对照
- **三种配色**：宣纸 / 碑拓 / 藏经
- **导出**：单字 JPG 图片、GIF 演变图（含自研 GIF 编码器），支持批量导出
- **`#z=字` 参数**：`index.html#z=江` 直接打开某个字，方便分享
- 单页应用，**离线可用**（字体按需子集内嵌，不联网、不依赖对方装字体）

## 已知局限

- **甲骨文只覆盖 1,425 字** —— 这是甲骨学界的客观上限（已释字约 1,600），换字体也突破不了
- **《说文》的文字说解本身有系统性错误** —— 许慎成书于东汉，未见甲骨文，传统所称「释形、释义、引例、分部、妄羼」五误即是。本页只标注、不篡改，因为「东汉人怎么理解这个字」同样是知识
- **中古音／上古音未覆盖全部字**（7,964 / 3,163），多音字只取一个主要读音
- **谐声系列**由《说文》「从××聲」自动归并，个别字可能因释文异文而归属有误
- 上古音构拟与中古音转写均为**学术构拟**，非历史真实读音

## 技术说明

- 单页 HTML + 内联数据，无框架、无依赖
- 字体用 `pyftsubset` 按需子集（完整字体 25.8 MB → 8.5 MB woff2）
- 自写 **GIF89a 编码器**（固定调色板 + LZW）—— 浏览器原生不支持 GIF 编码
- 演变动画、导出功能均为 Canvas 实现

## 缘起

一位学汉语言文学的朋友和她舍友聊出来的点子：既然电脑里已经有小篆和甲骨文字体了，能不能做一个"查一个字就能看到它怎么来的"页面，好分享、又有专业性。于是有了这个。
